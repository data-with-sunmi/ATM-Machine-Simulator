#  ATM Machine Simulator

This project simulates the core functions of an ATM using Python.  
It allows users to:
- Check balances
- Withdraw and deposit money
- Exit securely

##  Project Overview
The program mimics a basic ATM interface through command-line prompts, using Python control structures and functions to manage transactions.

##  Technologies Used
- Python 3
- Jupyter Notebook (for simulation and testing)

## File Description
`ATM Machine Simulator.ipynb` → The main notebook containing all code cells and simulation logic.

## How to Run
1. Open the notebook in **Jupyter** or **Google Colab**.
2. Run each cell sequentially.
3. Follow the on-screen prompts to perform ATM operations.
